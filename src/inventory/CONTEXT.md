# 库存

数量账的唯一所有者。任何在库/可用/冻结的增减必须留下关联业务单据的流水；其它上下文不得直接改账。

## Language

**库存余额**：
某一仓库内、某一 SKU 在某一库位上的数量账（MVP 维度：仓库 + SKU + 库位，不强制批次）。
_Avoid_: 库存记录、stock（口语混用）

**在库数量**：
该余额上行上实际仍在库内的数量。
_Avoid_: 总库存（易与多库位汇总混淆）

**冻结数量**：
在库数量中因业务预留而暂不可被其它出库扣减的部分（典型：出库单审核通过后的分配/预留）。**不是**盘点锁——盘点锁卡的是库位作业，不靠把数量记入冻结数量来实现。
_Avoid_: 锁定、占用（与库位「占用」状态混淆）、盘点锁

**可用数量**：
可被出库扣减的数量；定义为 在库数量 − 冻结数量。
_Avoid_: 可售（电商口径，本仓未必等价）

**库存流水**：
一次导致库存余额变化的不可篡改明细，必须关联业务单据与单据行，并对应一次上架/拣货/盘盈盘亏等执行。同一单据行允许对应多笔流水（部分上架/部分拣货）。**不是**操作日志——操作日志记录谁做了什么动作，流水记录账为何从 A 变为 B。
_Avoid_: 日志（过宽）、变动记录（弱）、操作日志

**实扣**：
将已分配的冻结数量转为真正出库：冻结数量与在库数量同时减少。由拣货确认触发，不是审核触发。
_Avoid_: 扣库存（过宽，未区分预留与实扣）

**释放预留**：
将尚未实扣的冻结数量改回可用；在库数量不变。由出库取消未拣部分等业务触发，须留可审计痕迹（流水或等价记录）。
_Avoid_: 解锁、回滚（过宽）

**库存预警**：
某仓库内某 SKU 的可用数量（可跨库位汇总）低于该 SKU 的安全库存时产生的预警事实；数量回升到阈值及以上时关闭或解除。展示层只读，不在其它上下文重复生成规则。
_Avoid_: 告警、通知（过宽，易与消息推送混淆）
