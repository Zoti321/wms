# 出库

管理货离开仓库的单据与拣货过程。不拥有库存数量；扣减成功以库存记账结果为准。

出库审核 = **分配（预留）**；拣货确认 = **预留实扣**。中间不存在「只校验不预留」的审核。

## Language

**出库单**：
一次出库业务的单据聚合，归属某一仓库；类型包括销售出库、领料出库、其他出库。
_Avoid_: 发货单（若未单独建模承运发运）、订单（易与外部销售单混淆）

**出库单行**：
出库单上按 SKU（及计划数量）拆分的明细；审核时按行分配，可多次拣货，直到累计拣货数量达到已分配数量。
_Avoid_: 明细（单独用时过宽）

**出库单状态**：
草稿 → 待审核 → 已审核 → 拣货中 → 已完成 / 已取消。全部行拣货完成后单据自动已完成；已完成与已取消不可再编辑。
_Avoid_: 随意同义状态名

**分配（预留）**：
出库单审核通过时，按行在库存上将对应可用数量转为冻结数量，保证后续拣货不被其它单据抢走。MVP：任一出库单行可用不足则**整单审核失败**，不落任何预留；不按行部分成功，也不拆单（拆单为二期）。
_Avoid_: 冻结（单独说）、锁库存（与盘点锁混淆）、部分分配（MVP）

**拣货**：
针对出库单行的一次执行：从指定库位取出本次数量，请求库存将对应冻结转为实扣；允许同一行多次拣货（部分拣货）。盘点锁覆盖的库位不可拣货。
_Avoid_: 出库（指整张单据时不要用「拣货」代替）

**拣货记录**：
一次拣货执行在出库上下文中的留痕，与一笔库存流水对应。
_Avoid_: 拣货日志

**释放预留**：
取消尚未实扣的分配：将对应冻结数量改回可用。已实扣数量不在释放范围内。
_Avoid_: 取消分配（易被理解成整单作废）、解锁

**出库取消**：
终止出库单（或行）的未完成部分。若已有拣货实扣，已出库数量不可随取消抹掉，须另走退货入库或冲销；未拣部分先释放预留，再将单据/行置为已取消或已完成（按是否仍有实扣区分）。
_Avoid_: 删除出库单、直接改库存回滚
