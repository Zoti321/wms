# 主数据

仓库运营所依赖的参照数据：货是什么、放在哪、跟谁往来。不负责数量账。

MVP 只启用一个仓库，但模型始终以 **仓库** 为一等概念；库存与作业单据均归属某一仓库。

## Language

**仓库**：
一个独立核算与作业的库存场所。单据、库位与库存余额均归属某一仓库。
_Avoid_: 仓（口语可，正式文档与模型用「仓库」）、站点（易与门店混淆）

**商品（SKU）**：
可独立库存与出入库的最小货品单位，含编码、名称、规格、单位、条码与启用状态。SKU 主数据可跨仓库共享；库存数量按仓库分隔。
_Avoid_: 物料（除非特指原材料仓且已单独建模）、货品（口语）

**安全库存**：
某 SKU 在业务上期望保持的最低库存水平（阈值属主数据；是否触发预警由库存上下文按仓库汇总可用量判定）。
_Avoid_: 最低库存、警戒线（口语）

**库区**：
某仓库内的空间分区，位于「仓库」之下、「库位」之上。
_Avoid_: 区域（过宽）

**库位**：
可指定存放的最小空间单元；层级为仓库 → 区 → 排 → 位。
_Avoid_: 货架、位置（口语）

**库位状态**：
库位作为空间资源的状态：空闲 / 占用 / 冻结（禁止再往该库位上架或从该库位出库，具体禁令由库存/作业策略消费）。
_Avoid_: 与「冻结数量」混用——那是库存上下文的数量口径

**供应商**：
向仓库供货的组织，用于入库单关联。
_Avoid_: 厂商（除非另有型号维度）

**客户**：
从仓库取货或被发货的组织/个人，用于出库单关联（MVP 轻量）。
_Avoid_: 买家、账号
