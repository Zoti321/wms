# 盘点

核对账实差异并在审核后请求库存调整。实盘差异在主管审核通过前不落库存账。

MVP 对齐常见生产 WMS 做法：盘点范围对**库位加盘点锁**，锁定期内禁止对该库位上架与出库；这与库存上下文的「冻结数量」（出库预留）不是同一机制。

## Language

**盘点单**：
按某仓库的库区或全仓发起的一次账实核对单据。
_Avoid_: 盘库单、库存检查单

**盘点锁**：
盘点单生效后，对其覆盖库位施加的作业锁：禁止上架与拣货/出库，直到盘点单取消或审核完成并释放。实现上体现为主数据侧库位进入不可作业状态，或由库存拒绝针对这些库位的增减请求（二者只选一种作为系统真相，见 ADR 若需要）。
_Avoid_: 冻结数量、冻结（单独使用时过宽）

**实盘数量**：
盘点时现场清点得到的数量；在审核前只存在于盘点单，不改库存余额。
_Avoid_: 实际库存（易被理解成已落账）

**盘盈 / 盘亏**：
实盘相对账面的多出或缺少；审核通过后由库存一次性调整并记流水。
_Avoid_: 直接说「改库存」而不提盈亏单据
