# 入库

管理货进入仓库的单据与上架过程。不拥有库存数量；上架成功以库存记账结果为准。

## Language

**入库单**：
一次入库业务的单据聚合，归属某一仓库；类型包括采购入库、退货入库、其他入库。
_Avoid_: 收货单（若未单独建模收货）、ASN（二期概念）

**入库单行**：
入库单上按 SKU（及计划数量）拆分的明细；可多次上架，直到累计上架数量达到计划数量。
_Avoid_: 明细（单独用时过宽）

**入库单状态**：
草稿 → 待审核 → 已审核 → 上架中 → 已完成 / 已取消。全部行上架完成后单据自动已完成；已完成与已取消不可再编辑。已上架数量不可靠「取消」抹掉，纠错走调整或二期冲销。
_Avoid_: 随意同义状态名（如「关闭」代替「已完成」）

**上架**：
针对入库单行的一次执行：指定库位与本次数量，请求库存增加在库（及可用）；允许同一行多次上架（部分上架）。盘点锁覆盖的库位不可上架。
_Avoid_: 入库（指整张单据时不要用「上架」代替）

**上架记录**：
一次上架执行在入库上下文中的留痕，与一笔库存流水对应（同一业务事实的两端）。
_Avoid_: 上架日志
