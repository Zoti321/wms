# 系统架构与模块划分

## 系统架构

```
┌──────────────┐  ┌──────────────┐
│  Web Admin   │  │ Mini Program │
│  (Vue 3)     │  │ (作业端)      │
└──────┬───────┘  └──────┬───────┘
       │ HTTPS/JSON      │
       └────────┬────────┘
                ▼
       ┌────────────────────┐
       │  wms-api (FastAPI) │
       │  Auth · ACL · API  │  ← 平台：身份 / 操作日志
       └─────────┬──────────┘
                 │
    ┌────────────┼────────────────────────────┐
    ▼            ▼            ▼               ▼
 catalog     inbound      outbound        stocktake
    │            │            │               │
    └────────────┴─────┬──────┴───────────────┘
                       ▼
                  inventory   ← 唯一改账 + ledger + 预警
                       ▼
                  MySQL 8.0 (InnoDB)
```

### 分层约定

- **Controller**：参数校验、鉴权、DTO，不含库存规则
- **Application**：用例编排（如 `approveOutbound` → 调用库存分配）
- **Domain（按上下文）**：状态机、分配/实扣/盘点锁策略
- **Infrastructure**：SQLAlchemy 同步仓储、JWT（Access）、操作日志持久化

## 模块划分

| 包 | 职责 |
|----|------|
| **catalog · 主数据** | 仓库、SKU、库区库位、供应商/客户、安全库存阈值 |
| **inventory · 库存** | 余额、分配/实扣/释放、流水、库存预警。唯一写库存表 |
| **inbound · 入库** | 入库单/行、审核、上架记录；请求库存增加 |
| **outbound · 出库** | 出库单/行、审核分配、拣货实扣、取消释放预留 |
| **stocktake · 盘点** | 盘点单、盘点锁、实盘、盈亏审核请求调账 |
| **platform · 身份与审计** | 用户角色、菜单权限、操作日志。非领域上下文 |
