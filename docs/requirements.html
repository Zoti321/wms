需求已按限界上下文拆成 Markdown 模块，便于人读目录、Agent 按任务局部加载。术语以 领域模型 为准；本页只做导航。

模块

00 · OVERVIEW

总览

背景目标、MVP 范围、角色、非功能、全局业务规则。
01 · CATALOG

主数据

仓库、SKU、库位、供应商/客户。
02 · INVENTORY

库存

唯一账本、流水、预警、分配/实扣记账。
03 · INBOUND

入库

入库单、部分上架、上架记录。
04 · OUTBOUND

出库

分配预留、拣货实扣、取消释放。
05 · STOCKTAKE

盘点

盘点锁、实盘、盈亏审核。
06 · PLATFORM

平台

登录鉴权、角色权限、操作日志、字典。

Agent 怎么用

  1. 打开 README 地图，按任务选模块。
  2. 读该模块 MD + 对应 src/<ctx>/CONTEXT.md。
  3. 涉及跨模块硬约束时加读 overview.md。
  4. 表结构 / API 以 开发文档 为准，需求模块不重复。
