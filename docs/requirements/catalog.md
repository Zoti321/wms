# 主数据（catalog）

术语：[`src/catalog/CONTEXT.md`](../../src/catalog/CONTEXT.md)  
实现：[`docs/development.html`](../development.html)（模块 catalog）

## 目标与范围

**做：** 维护仓库、商品（SKU）、库区/库位、供应商与客户等参照数据，供入出库与库存引用。

**不做：** 不拥有、不修改库存数量；不做批次/保质期主数据（二期）；MVP 不启用多仓库作业（模型仍保留仓库一等概念）。

## 业务规则

1. **仓库**为一等概念；单据、库位、库存余额均归属某一仓库。MVP 只启用一个仓库。
2. **SKU** 主数据可跨仓库共享；库存数量按仓库分隔。
3. 库位层级：仓库 → 区 → 排 → 位。库位状态（空闲/占用/冻结）是**空间资源**语义，勿与库存「冻结数量」混淆。
4. 供应商/客户为轻量主数据，用于单据关联。
5. 主数据删除采用「停用」；有历史单据的 SKU 不可物理删除。
6. **安全库存**是 SKU 上的阈值；是否触发**库存预警**由库存上下文判定（本模块不生成预警）。

（原全局故事未单列主数据创建时，以实现「建仓库/SKU/库位」主路径验收为准。）

## 验收标准

- 可创建并启用一个默认仓库；SKU、库位均关联该仓库（库位）或可被该仓库存引用（SKU）。
- 停用 SKU 后不可被新单据选用；已有历史单据仍可查询。
- 库位状态变更不影响库存「冻结数量」口径（两套概念可区分说明）。
