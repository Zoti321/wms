# 平台：身份、权限与审计（platform）

本模块**不是**领域限界上下文（见 `CONTEXT-MAP.md` 排除说明）。  
实现：[`docs/development.html`](../development.html)（platform / IAM）

## 目标与范围

**做：** 用户与角色、菜单/接口级鉴权、登录（账号密码 + bcrypt）、基础字典、**操作日志**；基础报表入口所需的只读聚合可挂在此或展示层（日报、CSV 导出）。

**不做：** 不拥有库存数量真相；操作日志不替代库存流水；MVP 无 Refresh Token、不上 Redis 会话存储。

## 业务规则

1. 按角色鉴权；无权限用户不能审核单据或改库存相关接口。
2. 密码加密存储（bcrypt）；仅发放 Access JWT（MVP）。
3. 敏感操作（登录、单据审核等）写**操作日志**，可按人/时间查询。
4. 操作日志与库存流水分开存储与查询。
5. 基础字典：单位、单据类型、取消原因等。

## 验收标准

- 无权限用户无法审核单据。
- 关键操作写入操作日志，且可与流水分别查询。
- 登录成功返回可调用受保护 API 的 Access Token。
