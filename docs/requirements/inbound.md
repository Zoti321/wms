# 入库（inbound）

术语：[`src/inbound/CONTEXT.md`](../../src/inbound/CONTEXT.md)  
实现：[`docs/development.html`](../development.html)（模块 inbound）

## 目标与范围

**做：** 入库单生命周期与按行上架；请求库存增加在库数量。

**不做：** 不直接改库存表；不建模独立 ASN/质检单（MVP）；已上架数量不靠「取消」抹账。

## 业务规则

1. 入库单归属仓库；类型：采购入库 / 退货入库 / 其他入库。
2. 状态：草稿 → 待审核 → 已审核 → 上架中 → 已完成 / 已取消。已完成与已取消不可再编辑。
3. 按**入库单行**上架：指定库位与本次数量；支持部分上架；每次上架产生**上架记录**，并请求库存记账写流水。
4. 上架成功以库存记账成功为准；**盘点锁**覆盖的库位不可上架。
5. 全部行累计上架达标后单据自动已完成。
6. 未上架可取消；已上架数量不可靠取消抹掉，纠错走调整或二期冲销。

## 用户故事

| 编号 | 作为… | 我希望… | 以便… |
|---|---|---|---|
| US-01 | 仓管员 | 创建采购入库单并按行多次上架到指定库位 | 货物分批入账且流水可追溯 |

## 验收标准

- 部分上架多次后，行累计数量与多笔流水、最终在库一致。
- 盘点锁库位上架被拒绝。
- 未上架单据可取消；已上架后取消不得抹掉已入账数量。
