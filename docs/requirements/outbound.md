# 出库（outbound）

术语：[`src/outbound/CONTEXT.md`](../../src/outbound/CONTEXT.md)  
实现：[`docs/development.html`](../development.html)（模块 outbound）

## 目标与范围

**做：** 出库单生命周期；审核时**分配（预留）**；拣货时**实扣**；取消未拣时**释放预留**。

**不做：** 不直接改库存表；MVP 无波次拣货/承运发运单；已实扣不靠取消抹账。

## 业务规则

1. 出库单归属仓库；类型：销售出库 / 领料出库 / 其他出库。
2. 状态：草稿 → 待审核 → 已审核 → 拣货中 → 已完成 / 已取消。
3. **审核 = 分配（预留）**：按行可用 → 冻结；不足则拒绝或按策略拆单。
4. **拣货 = 预留实扣**：按行从指定库位实扣；支持部分拣货；每次产生**拣货记录**与流水。
5. **出库取消**：未拣部分先释放预留；已实扣不可抹账，纠错走**退货入库**（或二期冲销）。
6. 盘点锁覆盖的库位不可拣货。
7. 不存在「审核只校验、中间不预留」的路径（见 overview 全局规则）。

## 用户故事

| 编号 | 作为… | 我希望… | 以便… |
|---|---|---|---|
| US-02 | 仓库主管 | 审核出库单完成分配预留 | 后续拣货不被其它单据抢走库存 |
| US-03 | 仓管员 | 按出库单从指定库位部分拣货确认 | 正确实扣并完成发货 |
| US-04 | 仓库主管 | 取消已部分拣货出库单的未拣部分 | 释放预留且不抹掉已出库数量 |

## 验收标准

- 审核后冻结量增加、可用下降；拣货后在库与冻结同减。
- 部分拣货后取消未拣：预留释放正确，已实扣数量不变。
- 库存不足时审核（分配）被拒绝。
- 盘点锁库位拣货被拒绝。
