# 库存（inventory）

术语：[`src/inventory/CONTEXT.md`](../../src/inventory/CONTEXT.md)  
实现：[`docs/development.html`](../development.html)（模块 inventory）

## 目标与范围

**做：** 作为数量账的**唯一所有者**——余额查询、分配/实扣/释放预留的记账、库存流水、库存预警的生成与解除。

**不做：** 不拥有入出库/盘点单据状态机；不替代操作日志；MVP 不上 Redis；不做批次维度。

## 业务规则

1. 其它上下文不得直接改库存表；一切增减经本上下文记账并写**库存流水**（关联单据与单据行）。
2. 余额维度：仓库 + SKU + 库位。
3. 可用数量 = 在库数量 − 冻结数量；分配只能占用可用数量。
4. **实扣**由拣货触发（冻结与在库同减）；**释放预留**由出库取消未拣等触发（仅减冻结）。
5. 同一单据行允许对应多笔流水（部分上架/部分拣货）。
6. **库存预警**：某仓某 SKU 汇总可用量低于安全库存时生成，回升至阈值及以上后解除；展示层只读；在记账成功后**同步判定**（MVP 无独立任务队列）。
7. 流水 ≠ 操作日志。

## 验收标准

- 库存不足时出库分配被拒绝，且无负可用/负在库。
- 两人几乎同时分配同一库存时不超卖。
- 流水可按单据行查询，且与余额变动一致。
- 低于安全库存产生预警，回升后解除。
