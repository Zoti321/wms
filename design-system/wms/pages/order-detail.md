# Page Override — 单据详情（入库 / 出库）

> Master: [`../MASTER-MINI.md`](../MASTER-MINI.md)  
> 适用：`pages/inbound/detail`、`pages/outbound/detail`

## 目标

只读展示单据摘要；列出**待处理行**，进入上架/拣货执行。

## 布局

```
┌─────────────────────────────┐
│ ← 入库详情 / 出库详情        │
├─────────────────────────────┤
│ ┌─ 摘要卡片 ─────────────┐  │
│ │ IN20250824001  [上架中] │  │
│ │ 采购入库 · 默认仓        │  │
│ └─────────────────────────┘  │
├─────────────────────────────┤
│ 待处理行                     │
│ ┌─────────────────────────┐ │
│ │ SKU-001  示例商品        │ │
│ │ 计划 100  已上 40        │ │
│ │              [ 上架 → ] │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ SKU-002 …               │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

## 摘要区

- 单号：`.font-data` 大号
- 状态 Tag + 类型 + 仓库名
- 备注：若有，24rpx muted，最多 2 行 ellipsis

## 行列表

| 列 | 入库 | 出库 |
|---|---|---|
| SKU | 编码 + 名称 | 同左 |
| 数量 | 计划 / 已上架 | 已分配 / 已拣 |
| 操作 | 「上架」 | 「拣货」 |

仅展示剩余量 &gt; 0 的行。行操作按钮：文字 Primary 或小型 solid 按钮，热区 88rpx。

## 出库差异

- 状态「已审核」表示已完成分配（预留），文案用「已分配」辅助说明，**不要**写「已出库」
- 拣货按钮文案：「拣货」，不用「出库」

## 空态

无待处理行：「本单已处理完成」+ 按钮「返回待办」

## 刷新

`onShow` 重新拉详情；从执行页返回后数量应更新。

## API

`GET /inbound-orders/{id}` 或 `GET /outbound-orders/{id}`
