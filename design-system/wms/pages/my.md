# Page Override — 我的（Tab）

> Master: [`../MASTER-MINI.md`](../MASTER-MINI.md)

## 目标

展示当前身份与仓库环境；提供退出登录。

## 布局

```
┌─────────────────────────────┐
│ 我的                         │
├─────────────────────────────┤
│  ┌─────────────────────────┐│
│  │  (头像占位 96rpx 圆形)    ││
│  │  zhangsan               ││
│  │  仓管员                  ││
│  └─────────────────────────┘│
├─────────────────────────────┤
│  当前仓库    默认仓（只读）   │
│  版本        0.0.0          │
├─────────────────────────────┤
│  ┌───────────────────────┐  │
│  │      退出登录           │  │  ← 次要按钮，outline 或 danger 文字
│  └───────────────────────┘  │
├─────────────────────────────┤
│   待办          我的         │
└─────────────────────────────┘
```

## 字段

| 项 | 来源 |
|---|---|
| 头像占位 | 圆形 + 用户名首字（不接微信头像） |
| 用户名 | `/auth/me`.username |
| 角色 | `ROLE_CODE_LABEL[role_code]` |
| 仓库 | MVP 单仓：种子仓名称，只读 |
| 版本 | `APP_VERSION` 常量（与 `manifest.json` `versionName` 对齐） |

## 交互

- **退出**：Modal 确认 → 清 Token + warehouse → `reLaunch` 登录页
- MVP **无**仓库切换、无设置项

## 样式

- 信息行：左 label muted，右 value foreground，行高 96rpx，底部分割线
- 退出按钮与底部 Tab 间距 ≥ 48rpx
