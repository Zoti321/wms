# Page Override — 拣货执行

> Master: [`../MASTER-MINI.md`](../MASTER-MINI.md)  
> 路由：`pages/outbound/pick`

## 目标

对**单行**执行拣货（实扣）：选择库位、输入本次拣货数量、确认。

## 布局

与 [inbound-putaway.md](./inbound-putaway.md) **对称**，文案替换：

| 上架 | 拣货 |
|---|---|
| 上架 | 拣货 |
| 已上 | 已拣 |
| 剩余可上 | 剩余可拣 |
| 确认上架 | 确认拣货 |

```
┌─────────────────────────────┐
│ ← 拣货                       │
├─────────────────────────────┤
│ ┌─ 行摘要 ────────────────┐ │
│ │ SKU-001  示例商品        │ │
│ │ 分配 50 · 已拣 20        │ │
│ │ 剩余可拣 30              │ │
│ └─────────────────────────┘ │
│  …（库位搜索 + Stepper）…    │
├─────────────────────────────┤
│       确认拣货               │
└─────────────────────────────┘
```

## 术语

- UI 用「拣货」「实扣」；**不要**写「确认出库」以免与整单完成混淆
- 「分配」数量指审核后的预留，不是已出库

## 字段规则

| 字段 | 规则 |
|---|---|
| 库位 | 必选；搜索选择 `location_id` |
| 数量 | 默认剩余可拣；上限剩余可拣 |

## 错误

| 情况 | 展示 |
|---|---|
| 库存不足 / 乐观锁 | 展示后端 message，建议返回详情刷新 |
| 409 盘点锁 | Modal，「该库位盘点锁定，无法拣货」 |

## API

`POST /outbound-orders/{orderId}/pick`  
Body: `{ line_id, location_id, qty }` + `Idempotency-Key`

## 成功

toast「拣货成功」→ 返回出库详情。
