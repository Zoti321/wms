# Page Override — 待办（Tab）

> Master: [`../MASTER-MINI.md`](../MASTER-MINI.md)

## 目标

聚合待上架入库单、待拣货出库单；仓管员从此进入作业。

## 布局

```
┌─────────────────────────────┐
│ 待办                    [↻] │  ← 可选轻量刷新 icon
├─────────────────────────────┤
│ [ 全部 ] [ 入库 ] [ 出库 ]   │  ← segment，高度 64rpx
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 入库 · IN20250824001    │ │
│ │ 采购入库  [上架中]       │ │
│ │ 更新于 10:32            │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 出库 · OUT20250824003   │ │
│ │ 销售出库  [拣货中]       │ │
│ └─────────────────────────┘ │
│         …                   │
├─────────────────────────────┤
│   待办          我的         │  TabBar
└─────────────────────────────┘
```

## TaskCard 规范

| 字段 | 样式 |
|---|---|
| 单号 | `.font-data` 32rpx 600 |
| 类型 | 24rpx muted |
| 状态 | `uni-tag` small，语义色见 Master |
| 待处理行数 | 24rpx muted，「待处理 N 行」（补全前可不显示） |
| 时间 | 24rpx muted，相对或绝对 |

卡片间距 `--space-md`；列表底部 padding ≥ TabBar + 32rpx。

## Segment 筛选

- 默认「全部」
- 切换仅客户端 filter，不闪全屏 loading（保留旧列表直至新数据返回）

## 刷新

- **下拉刷新**：标准微信动画
- **onShow**：后台静默刷新，不挡操作；**不闪** Skeleton
- 加载中：首屏（尚无任务数据）skeleton 2～3 卡片占位

## 空态

居中「暂无待办任务」+ 24rpx 说明「已完成任务请先在网页后台审核」

## 点击

| 卡片类型 | 跳转 |
|---|---|
| inbound | `/pages/inbound/detail?id=` |
| outbound | `/pages/outbound/detail?id=` |
