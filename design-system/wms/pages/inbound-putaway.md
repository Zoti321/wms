# Page Override — 上架执行

> Master: [`../MASTER-MINI.md`](../MASTER-MINI.md)  
> 路由：`pages/inbound/putaway`

## 目标

对**单行**执行上架：选择库位、输入本次数量、确认记账。

## 布局

```
┌─────────────────────────────┐
│ ← 上架                       │
├─────────────────────────────┤
│ ┌─ 行摘要 ────────────────┐ │
│ │ SKU-001  示例商品        │ │
│ │ 计划 100 · 已上 40       │ │
│ │ 剩余可上 60              │ │
│ └─────────────────────────┘ │
│                             │
│ 库位                         │
│ ┌───────────────────────┐   │
│ │ 搜索库位编码…          │   │
│ └───────────────────────┘   │
│ ┌ A-01-01  空闲 ────────┐   │  ← 候选列表
│ └───────────────────────┘   │
│                             │
│ 本次数量                     │
│   [ − ]    60    [ + ]      │
│                             │
│         （滚动区 bottom pad）│
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │       确认上架           │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

## 字段规则

| 字段 | 规则 |
|---|---|
| 库位 | 必选；`GET /locations?warehouse_id&code=` debounce 300ms |
| 数量 | 默认 = 剩余可上；范围 (0, 剩余可上] |
| 提交 | 未选库位或 qty 无效时禁用主按钮 |

## 库位候选行

- 展示：库位编码（`.font-data`）+ 库位状态（空闲/占用/冻结）
- `frozen`：**不可选**
- 选中：Primary 边框 + 浅蓝底（实现可用禁用态区分冻结）
- 盘点锁：列表无锁字段；**提交失败**专用 Modal（标题「无法作业」+ 后端 message），≠ 库位状态冻结

## 交互

1. 进入页：生成新 `Idempotency-Key`
2. 点确认：loading，POST putaway
3. 成功：toast + navigateBack
4. 失败：盘点锁 → Modal；其它 → toast / 顶部错误条，保留输入

## 错误文案

| 情况 | 展示 |
|---|---|
| 盘点锁（message 含「盘点锁定」） | Modal 标题「无法作业」，content 为后端 message |
| 其他 409/400 | 展示 `message`（Toast / 顶栏） |

## API

`POST /inbound-orders/{orderId}/putaway`  
Body: `{ line_id, location_id, qty }`

见 `docs/mini-program/api-client.md`。
